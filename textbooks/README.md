# textbooks/ — підручники (PDF) для роботи на комп'ютері

Сюди кладіть PDF підручників у **локальній** копії `teaching-studio` на вашому комп'ютері.
PDF-файли **не відправляються** в GitHub (`.gitignore`): вони великі й захищені авторським правом. Відправляється лише цей README.

Тому:
- **Claude на комп'ютері** (Claude Desktop → Code → папка `teaching-studio`) бачить ці PDF. Достатньо написати: «Go Getter 2, Unit 5, с. 45–47 — зроби урок».
- **Claude у хмарі / з телефона** цих файлів не бачить. Надсилайте фото сторінок або PDF прямо в чат.

Список підручників і їхніх файлів — у `../shared/textbooks.md`.
