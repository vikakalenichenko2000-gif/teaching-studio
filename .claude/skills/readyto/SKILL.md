Аргументи: $ARGUMENTS

Спершу прочитай: `ReadyTo/CLAUDE.md`, `shared/preferences.md`, `shared/rules.md`, `shared/readyto-formats.md`, `ReadyTo/platform-guide/mass-import.md`; для кожного використаного блоку — його файл у `ReadyTo/platform-guide/`.

Визнач, що просять:
- **одна/кілька вправ** → обери тип за таблицею «Вибір типу вправи» в `ReadyTo/CLAUDE.md`, напиши блоки у DOCUMENTED-синтаксисі;
- **цілий урок** → виконай кроки skill `readyto-lesson`;
- **фото/сторінка підручника/лексика** → витягни мовний матеріал, далі як вище;
- **як працює блок** → skill `readyto-guide`.

Обов'язково:
1. Лише синтаксис зі статусом DOCUMENTED або TESTED. Не вигадувати.
2. Англійська без помилок, одна однозначна відповідь, рівень учнів.
3. Збережи в `ReadyTo/lessons/` (урок) або `ReadyTo/exercises/` (окремі вправи) як `.txt` (чистий імпорт) + `.md` (ключі, Варіант B, статуси).
4. Запусти `python3 ReadyTo/tools/check_import.py <файл.txt>` — має бути 0 помилок.
5. У чаті: текст імпорту в блоці коду (копіювати кнопкою Copy) → ключ відповідей → ручні блоки (Варіант B) → статуси.
6. Попроси викладачку натиснути «Перевірити» в ReadyTo і повідомити результат; після підтвердження — статус TESTED у `shared/readyto-formats.md` + `changelog.md`.
7. Commit + push.
