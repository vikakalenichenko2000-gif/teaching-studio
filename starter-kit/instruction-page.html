Ваша AI-студія для підготовки уроків

Інструкція для викладачів Lingo. Один раз налаштовуєте, і далі Claude готує уроки на 60 хвилин, презентації та вправи для ReadyTo, Wordwall, Quizlet і Baamboozle у стилі школи.

Налаштування: 30–40 хвилин, один раз

Що знадобиться

Комп'ютерWindows 10/11 або Mac
Підписка ClaudePro або вище (без неї Claude Code не працює)
Google Chromeдля роботи Claude в ReadyTo
Архів студіїLingo-Teaching-Studio-Kit.zip — надішле колега

Паролі нікому не надсилайте, і Claude теж. Він працює у вашому браузері там, де ви вже увійшли.

Кроки

  1. 1Claude і застосунок для комп'ютера

    • Увійдіть на claude.ai. Перевірте, що план платний (Settings → Billing).
    • Завантажте застосунок: claude.ai/download → встановіть → увійдіть тим самим акаунтом.

  2. 2Git і Python лише Windows

    • Git for Windows: git-scm.com → Download for Windows → встановлення з налаштуваннями за замовчуванням.
    • Python: python.org → Downloads → Python 3. Під час встановлення поставте галочку «Add python.exe to PATH».
    • Повністю закрийте застосунок Claude і відкрийте знову.

    На Mac нічого не потрібно. Якщо Mac запропонує «інструменти розробника», погодьтеся.

  3. 3GitHub: там зберігатиметься студія

    • Зареєструйтеся на github.com (безкоштовно).
    • Встановіть GitHub Desktop з desktop.github.com і увійдіть.

  4. 4Розпакуйте архів

    Розпакуйте Lingo-Teaching-Studio-Kit.zip у Документи. Має вийти Документи\teaching-studio, а в ній папки teaching, ReadyTo, shared і файл ПОЧНИ-ТУТ.md.

    Якщо вийшла папка в папці, перенесіть внутрішню teaching-studio на рівень вище.

  5. 5Збережіть студію у своєму GitHub

    1. GitHub Desktop → File → Add local repository → Choose… → папка teaching-studio.
    2. Натисніть create a repository → Create repository.
    3. Угорі Publish repository, залиште Keep this code private → Publish.

  6. 6Перший запуск у Claude

    1. Застосунок Claude → вкладка Code → робота на цьому комп'ютері → папка Документи\teaching-studio.
    2. Скопіюйте промпт нижче (кнопка «Скопіювати промпт») і вставте його в Claude.
    3. Claude сам перевірить комп'ютер, поставить запитання про ваших учнів і налаштує студію під вас.

  7. 7Claude у Chrome для ReadyTo, Wordwall

    • Chrome Web Store → розширення Claude від Anthropic → Додати в Chrome → увійдіть тим самим акаунтом.
    • Увійдіть у ReadyTo як зазвичай. Якщо щось незрозуміло, напишіть у студії: «допоможи підключити Claude in Chrome».

  8. 8Робота з телефона за бажанням

    • claude.ai/connect-github → підключіть GitHub і встановіть Claude GitHub App для teaching-studio.
    • У застосунку Claude на телефоні: Claude Code → нова сесія → репозиторій teaching-studio.

Промпт для першого запуску

Цей самий текст лежить в архіві у файлі ПРОМПТ-ПЕРШИЙ-ЗАПУСК.txt.

Скопійовано 
Привіт! Це моя нова Teaching Studio — набір інструкцій, пам'яті та команд для підготовки уроків англійської у школі Lingo English School. Його мені передала колега, і вона вже налаштувала й протестувала систему. Тепер налаштуй її під мене.

Працюй українською, простими словами, крок за кроком. Я не програміст. Ніколи не проси в мене паролі.

1. ПРОЧИТАЙ СИСТЕМУ
Прочитай CLAUDE.md, teaching/CLAUDE.md, ReadyTo/CLAUDE.md і всі файли в shared/. Коротко (5–7 пунктів) скажи, що вмієш у цій студії.

2. ПЕРЕВІР МІЙ КОМП'ЮТЕР
Перевір, чи є git і python (python або python3 або py). Якщо чогось бракує — поясни, що встановити й де натиснути (Windows: Git for Windows з git-scm.com, Python з python.org з галочкою «Add python.exe to PATH»). Потім запусти перевірку:
python ReadyTo/tools/check_import.py ReadyTo/tested/2026-11-09_all-16-types-TESTED.txt
Має бути «помилок: 0». Перевір, що всі команди з CLAUDE.md є в .claude/skills/.

3. ПЕРСОНАЛІЗАЦІЯ
Постав мені по черзі (не всі одразу, по 2–3) такі запитання:
- як до мене звертатися;
- яких учнів я веду: класи/вік, рівні, групові/індивідуальні/парні, онлайн чи офлайн;
- чи є учні, які ще не читають;
- за якими підручниками я працюю (і чи покладу PDF у папку textbooks);
- який у мене тариф Wordwall (Standard чи Pro), Quizlet, Baamboozle — чи вони платні;
- чи працюю я в ReadyTo (акаунт школи Lingo Eng School);
- чи все в шкільних налаштуваннях (shared/preferences.md: урок 60 хв, 5 етапів, Google Slides, бренд Lingo, Lingo Coins) підходить і мені, чи щось у мене інакше.
Записуй мої відповіді в shared/preferences.md, shared/students.md, shared/textbooks.md, shared/interactive-game-preferences.md. Те, що я не підтвердила, — у shared/pending-confirmation.md. Кожну зміну — рядок у shared/changelog.md.

4. ЗБЕРЕЖЕННЯ В GITHUB
Перевір, що папка — git-репозиторій з remote origin (я публікувала її через GitHub Desktop). Якщо ні — поясни, як зробити «Add local repository → create a repository → Publish repository (private)» у GitHub Desktop. Після налаштування зроби commit і push. Якщо push не вдається — скажи мені натиснути «Push origin» у GitHub Desktop.
Онови рядок «Зберігання» в CLAUDE.md: вкажи назву МОГО репозиторію.

5. ТЕСТ READYTO (якщо я працюю в ReadyTo)
Поясни, як створити в ReadyTo тестовий урок і через «Імпорт зі списку (кілька вправ)» вставити вміст ReadyTo/tested/2026-11-09_all-16-types-TESTED.txt, натиснути «Перевірити» й «Створити вправи». Я скажу результат — запиши в shared/readyto-formats.md (журнал тестів).

6. ЯК КОРИСТУВАТИСЯ
Наприкінці дай мені коротку шпаргалку: головні команди (/lesson, /readyto-lesson, /wordwall, /quizlet, /baamboozle, /slides, /remember), як надсилати фото підручника, як працювати з телефона (claude.ai/connect-github → репозиторій teaching-studio), і як підключити Claude in Chrome, щоб ти міг працювати прямо в ReadyTo.

Правила, яких дотримуйся завжди: не вигадуй функцій платформ, позначай що перевірено, а що ні; з підручника бери лише матеріал, вправи створюй власні; англійська без помилок; після кожної завершеної роботи — commit і push.

Підручники: покладіть PDF у папку teaching-studio\textbooks і назвіть їх Claude. Далі пишіть: «Unit 4, сторінки 30–31». Claude бере з підручника лише матеріал, а вправи складає свої.

Якщо щось не працює

  • Немає вкладки Code або вона не відкривається: перевірте крок 2 і перезапустіть Claude.
  • «python не знайдено»: перевстановіть Python з галочкою «Add python.exe to PATH».
  • Будь-що інше: напишіть Claude «щось не працює» і вставте текст помилки.
