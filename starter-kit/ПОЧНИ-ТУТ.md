# Teaching Studio для викладачів Lingo English School

Це ваша особиста AI-студія для підготовки уроків. Вона знає:
- структуру уроку школи (60 хв: Warming up → лексика через ігри → граматика → тексти → міні-тест);
- бренд Lingo (кольори, шрифти, котик, Lingo Coins);
- як робити вправи для **ReadyTo** (30 довідників; формати перевірені на платформі), **Wordwall**, **Quizlet**, **Baamboozle**;
- шаблони уроків, презентацій (Google Slides), роздаток, ігор і руханок.

Ви надсилаєте фото сторінки підручника, тему або список слів, а Claude готує урок і вправи для платформ.

Налаштування займе **30–40 хвилин один раз**. Робіть кроки по черзі. Паролі нікому не надсилайте (і Claude теж: він їх не потребує).

---

## Що потрібно
- Комп'ютер з **Windows 10/11** або **Mac**.
- **Платна підписка Claude** (Pro або вище; або шкільний акаунт, якщо школа його надає). Без неї Claude Code не працює.
- Браузер **Google Chrome**.
- Безкоштовний акаунт **GitHub**: там зберігатиметься ваша студія.

---

## Крок 1. Claude
1. Зареєструйтеся або увійдіть на **claude.ai** (краще особистою поштою, бо це ваш робочий інструмент).
2. Переконайтеся, що у вас платний план (Settings → Billing).
3. Завантажте застосунок **Claude для комп'ютера**: **claude.ai/download** → встановіть → увійдіть тим самим акаунтом.

## Крок 2. Git і Python (потрібні, щоб Claude міг працювати з файлами)
**Windows:**
1. **Git for Windows**: **git-scm.com** → Download for Windows → встановіть з усіма налаштуваннями за замовчуванням (просто «Next»).
2. **Python**: **python.org** → Downloads → Python 3 → під час встановлення **обов'язково поставте галочку «Add python.exe to PATH»** → Install Now.
3. **Перезапустіть** застосунок Claude (закрийте повністю й відкрийте знову).

**Mac:** нічого встановлювати не потрібно. Якщо Mac попросить «встановити інструменти розробника», погодьтеся.

## Крок 3. GitHub (збереження студії)
1. Зареєструйтеся на **github.com** (Sign up).
2. Завантажте **GitHub Desktop**: **desktop.github.com** → встановіть → увійдіть у свій GitHub.

## Крок 4. Розпакуйте студію
1. Архів `Lingo-Teaching-Studio-Kit.zip` (вам його надішле колега) розпакуйте в **Документи**.
   Має вийти папка **`Документи\teaching-studio`**, а в ній папки `teaching`, `ReadyTo`, `shared` і файл `CLAUDE.md`.
2. Якщо після розпакування вийшла папка в папці (`teaching-studio\teaching-studio`), перенесіть внутрішню на рівень вище.

## Крок 5. Підключіть студію до GitHub
1. GitHub Desktop → **File → Add local repository** → **Choose…** → оберіть папку `teaching-studio`.
2. Програма напише, що це ще не репозиторій. Натисніть **«create a repository»** → **Create repository**.
3. Угорі натисніть **Publish repository**. Залиште галочку **«Keep this code private»** → **Publish**.
Готово: студія збережена у вашому приватному GitHub.

## Крок 6. Відкрийте студію в Claude
1. Застосунок Claude → вкладка **Code**.
2. Оберіть роботу **на цьому комп'ютері** (Local) і папку **`Документи\teaching-studio`**.
3. Відкрийте файл **`ПРОМПТ-ПЕРШИЙ-ЗАПУСК.txt`** (лежить поруч із цим файлом), скопіюйте **весь** текст і вставте в Claude → Enter.
4. Далі Claude сам усе перевірить, поставить вам кілька запитань про ваших учнів і налаштує студію під вас.

## Крок 7. Claude у Chrome (щоб Claude міг працювати прямо в ReadyTo чи Wordwall)
1. У Chrome відкрийте **Chrome Web Store** → знайдіть **Claude** (від Anthropic) → **Додати в Chrome**.
2. Увійдіть у розширення тим самим акаунтом Claude.
3. Увійдіть у ReadyTo / Wordwall у Chrome як зазвичай. Claude працюватиме у вашому браузері, і пароль йому не потрібен.
Якщо щось незрозуміло, напишіть Claude у студії: «допоможи підключити Claude in Chrome».

## Крок 8. Робота з телефона (за бажанням)
1. На **claude.ai/connect-github** підключіть свій GitHub і встановіть **Claude GitHub App** для репозиторію `teaching-studio`.
2. У застосунку Claude на телефоні відкрийте Claude Code → нова сесія → оберіть репозиторій `teaching-studio`.

## Як користуватися щодня
Пишіть звичайними словами або командами:

| Команда | Що робить |
|---|---|
| `/lesson` | повний урок на 60 хв |
| `/slides` | презентація для Google Slides |
| `/readyto-lesson` | урок для ReadyTo (текст для «Імпорт зі списку») |
| `/readyto` | вправи ReadyTo |
| `/readyto-check` | перевірити текст імпорту ReadyTo |
| `/wordwall` · `/quizlet` · `/baamboozle` | матеріали для цих платформ |
| `/interactive` | з одного матеріалу: Quizlet + Wordwall + Baamboozle |
| `/games` · `/brainbreak` | ігри й руханки |
| `/vocabulary` · `/grammar` · `/worksheet` · `/review` · `/adapt` | лексика, граматика, роздатки, повторення, адаптація рівня |
| `/remember` | запам'ятати ваше побажання назавжди |

Приклад: надішліть фото сторінки підручника й напишіть: «/readyto-lesson 3 клас, A1».

**Підручники:** покладіть PDF у папку `teaching-studio\textbooks` і скажіть Claude їхні назви. Далі достатньо писати «Smart Junior 3, Unit 4, с. 30–31».

**Збереження:** після кожної роботи Claude сам зберігає зміни в GitHub. На іншому комп'ютері: GitHub Desktop → **Pull origin**.

## Якщо щось не працює
- Вкладки Code немає або вона не відкривається → перевірте Крок 2 і перезапустіть Claude.
- «python не знайдено» → перевстановіть Python з галочкою «Add python.exe to PATH».
- Будь-яка інша проблема → напишіть Claude: «щось не працює: …» і вставте текст помилки.
