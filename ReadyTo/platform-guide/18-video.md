# 18. Відео

> **Статус:** Сторінка: ✅ · Імпорт: ❌ → вручну
> Офіційна документація: https://readyto.net/docs/lesson-blocks/video
> Маркер масового імпорту: немає (лише вручну)
> Оновлено: 2026-11-09

## Призначення
Власний відеофайл із плеєром і опціональним скриптом.

## Для яких навчальних цілей
власні записи, пояснення, сценки; питання до перегляду.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Відео».
2. «Оберіть відео» (mp4 або mov, ≤250 МБ), дочекайтеся завантаження.
3. «Опціональний скрипт» (повне форматування).
4. «Зберегти».

## Поля
Заголовок · Опис (зручно для питань) · файл · скрипт.

## Точний синтаксис
Маркера немає → вручну. Якщо відео є на YouTube — беріть блок YouTube (не займає сховище).

## Формат масового імпорту
```
Немає.
```

## Приклад готового завдання
```
Опис: Watch and answer: 1) Where are they? 2) What do they order?
```

## Як виглядає для учня
Плеєр + кнопка «Скрипт +». Повний екран, швидкість, завантаження — залежить від браузера.

## Як перевіряються відповіді
Не перевіряється.

## Зображення та аудіо
mp4/mov до 250 МБ; займає сховище школи.

## Типові помилки
- Завантажувати те, що є на YouTube.
- Файл >250 МБ.

## Контрольний список
- [ ] формат і розмір
- [ ] питання в описі або окремим блоком

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
