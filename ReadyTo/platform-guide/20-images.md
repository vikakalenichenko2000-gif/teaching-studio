# 20. Картинка

> **Статус:** Сторінка: ✅ · Імпорт: ❌ → вручну
> Офіційна документація: https://readyto.net/docs/lesson-blocks/image
> Маркер масового імпорту: немає (лише вручну)
> Оновлено: 2026-11-09

## Призначення
Зображення з текстом поруч або на всю ширину; повноекранний перегляд; малювання на онлайн-уроці.

## Для яких навчальних цілей
ілюстрації до лексики, picture prompts для говоріння, граматичні ситуації, ілюстрації до історій.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Картинка».
2. «Клікніть або перетягніть» (jpg/png до 5 MB) або вставка з буфера.
3. Позиція: Зліва / Справа / По центру / На всю ширину (перемикач «Різна позиція для кожного зображення» → «шахівниця»).
4. Розмір: Довільний або Фіксований (16:9, 7:2…, з кадруванням).
5. Опціональний текст поруч.
6. «Зберегти».

## Поля
Заголовок · Опис · картинки · позиція · розмір · опціональний текст.

## Точний синтаксис
Маркера немає → вручну.

## Формат масового імпорту
```
Немає.
```

## Приклад готового завдання
```
Заголовок: Describe the picture. What are they doing?
(без підпису, який розкриває відповідь)
```

## Як виглядає для учня
Клік відкриває оригінал на весь екран (лупа). На онлайн-уроці — пензлик, малюнок синхронізується.

## Як перевіряються відповіді
Не перевіряється.

## Зображення та аудіо
jpg/png ≤5 MB. В уроці показуються стиснені копії, оригінал відкривається по кліку (важкі файли >1 MB вантажаться довше).

## Типові помилки
- Підпис, що розкриває відповідь у вправі на вгадування.
- Важкі фото.

## Контрольний список
- [ ] ≤5 MB, бажано <1 MB
- [ ] стиль картинок єдиний (бренд Lingo)
