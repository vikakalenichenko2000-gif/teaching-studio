# 05. Розставте речення по порядку

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/sort-sentences
> Маркер масового імпорту: `#SortSentences`
> Оновлено: 2026-11-09

## Призначення
Речення (репліки діалогу або навіть абзаци) перемішані; учень відновлює порядок. Одиниця — ціле речення/абзац (на відміну від Unscramble, де перемішуються слова).

## Для яких навчальних цілей
історії, діалоги, рецепти, інструкції, sequencing (first, then, after that, finally), reading.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Розставте речення по порядку».
2. Один блок = один текст/діалог/інструкція. Перше речення → Enter → наступне (або вставте готовий текст: кожен рядок стане реченням).
3. Порядок полів — за ⋮⋮, видалити — ×, «+ Додати речення».
4. «Додати блок» — ще один текст (автонумерація).
5. Налаштування: «Зайві речення», «Заголовок блоку», «Зображення»/«Аудіо» (до кожного блоку).
6. «Зберегти».

## Поля
Заголовок · Опис · блоки речень · зайві речення · заголовок блоку · картинка/аудіо до блоку.

## Точний синтаксис
- Речення у правильному порядку, по одному на рядок; редактор перемішує сам. ✅ DOCUMENTED
- Окремі тексти розділяйте порожнім рядком; у кожному ≥2 речень. ✅
- `~речення` — зайве речення (не входить у послідовність). ✅
- `=Назва` на початку рядка — заголовок групи. ✅

## Формат масового імпорту
```
#SortSentences: Заголовок
=Назва тексту (необов.)
Перше речення.
Друге речення.
~Зайве речення.
```

## Приклад готового завдання
```
#SortSentences: Put the story in the correct order.
First, we packed our bags.
Then, we went to the airport.
After that, we got on the plane.
Finally, we arrived in Spain.
~We stayed at home all summer.
```

## Як виглядає для учня
Картки з номером позиції; перестановка стрілками ▲▼ або перетягуванням (на телефоні — затиснути). Зайві речення — у блок «Зайве» (лічильник «Зайве — 1 з 2»).

## Як перевіряються відповіді
«Перевірити» — коли в списку рівно стільки речень, скільки в тексті. Зелений/червоний; бал = кількість речень на своїх місцях (правильно відкладені зайві теж). Крапки історії (4 спроби); після 3 невдалих — «Показати відповіді». Онлайн: бачите перестановки наживо, «відповіді всіх» (напр. 4/6), «Пройти ще раз».

## Зображення та аудіо
«Зображення»/«Аудіо» до кожного **блоку** (напр. фото страви до рецепта, аудіо діалогу), «все або нічого». Вручну після імпорту.

## Типові помилки
- Кілька однаково логічних послідовностей → додайте маркери (First, Then…).
- Блок з одного речення не збережеться.
- «Заголовок блоку» ввімкнено → потрібен у всіх блоках.
- Зайве речення, що логічно вписується в історію.

## Контрольний список
- [ ] правильний порядок у файлі
- [ ] лише одна логічна послідовність
- [ ] ≥2 речення в кожному тексті
- [ ] зайве речення явно не з цієї історії
