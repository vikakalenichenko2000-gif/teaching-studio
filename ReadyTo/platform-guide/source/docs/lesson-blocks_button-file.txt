 Кнопка (завантаження PDF)
 PDF (до 100 МБ) прямо в уроці або кнопкою з вашою назвою.
 Заголовок і опис
Зверху блоку — два текстові поля:
- Заголовок — жирний і найбільший. Зазвичай сюди пишуть саме завдання.
- Опис — менший текст під заголовком (необов'язковий).
Як додати файл
- 1У «Як показати PDF» оберіть «Перегляд в уроці» або «Кнопка».
- 2Натисніть «Змінити файл» й оберіть PDF на вашому пристрої.
- 3Дочекайтесь повного завантаження, поруч з'явиться назва файлу.
- 4Для кнопки впишіть «Назву на кнопці» (наприклад, `Завантаж аркуш`).
- 5Збережіть блок.
[IMG: Редактор: завантажений PDF]
 - - 
 Підтримуються PDF до 100 МБ. Дочекайтесь повного завантаження, перш ніж зберігати блок. Для кнопки без назви на кнопці блок не збережеться.
Як виглядає в учня
Перегляд в уроці. Учень бачить сторінки PDF прямо в уроці, однаково в будь-якому браузері. Під сторінкою іконки (назва з'являється, якщо навести мишку):
- стрілки (або свайп на телефоні) гортають сторінки;
- «На весь екран» (або клік по сторінці) відкриває PDF великим, там його можна збільшити;
- «Завантажити» зберігає файл на пристрій.
Кнопка. Учень бачить заголовок і кнопку з вашою назвою. Натиснувши її, він відкриє файл у браузері або завантажить його.
