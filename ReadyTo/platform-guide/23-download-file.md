# 23. Кнопка (завантаження PDF)

> **Статус:** Сторінка: ✅ · Імпорт: ❌ → вручну
> Офіційна документація: https://readyto.net/docs/lesson-blocks/button-file
> Маркер масового імпорту: немає (лише вручну)
> Оновлено: 2026-11-09

## Призначення
PDF прямо в уроці (перегляд) або кнопкою з вашою назвою.

## Для яких навчальних цілей
worksheets, домашні, списки слів, тексти для читання, картки для друку.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Кнопка (завантаження PDF)».
2. «Як показати PDF»: «Перегляд в уроці» або «Кнопка».
3. «Змінити файл» → PDF; дочекатися повного завантаження.
4. Для кнопки — «Назва на кнопці» (обов'язково).
5. «Зберегти».

## Поля
Заголовок · Опис · режим · файл PDF · назва на кнопці.

## Точний синтаксис
Маркера немає → вручну.

## Формат масового імпорту
```
Немає.
```

## Приклад готового завдання
```
Назва на кнопці: Download the worksheet
```

## Як виглядає для учня
Перегляд: сторінки в уроці, стрілки/свайп, «На весь екран», «Завантажити». Кнопка: відкриває або завантажує файл.

## Як перевіряються відповіді
Не перевіряється.

## Зображення та аудіо
Лише PDF ≤100 МБ. Мої роздатки (`teaching/worksheets/`) експортуються в PDF.

## Типові помилки
- Зберегти до завершення завантаження.
- Кнопка без назви не зберігається.

## Контрольний список
- [ ] PDF відкривається
- [ ] назва на кнопці

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
