# 29. Файл учня

> **Статус:** Сторінка: ✅ · Імпорт: ❌ → вручну
> Офіційна документація: https://readyto.net/docs/lesson-blocks/student-file
> Маркер масового імпорту: немає (лише вручну)
> Оновлено: 2026-11-09

## Призначення
Учень надсилає фото або аудіо у відповідь; ви оцінюєте вручну. (На скриншоті розпізнано як «Файл чуня» — правильна назва «Файл учня».)

## Для яких навчальних цілей
фото письмової роботи з зошита, малюнок, запис читання вголос, усна відповідь, вимова.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Файл учня».
2. «Тип файлу»: Зображення або Аудіо (праворуч прев'ю «Як це побачить учень»).
3. «Зберегти».

## Поля
Заголовок · Опис · Тип файлу.

## Точний синтаксис
Маркера немає → вручну.

## Формат масового імпорту
```
Немає.
```

## Приклад готового завдання
```
Заголовок: Read the text aloud and record yourself. · Тип файлу: Аудіо
```

## Як виглядає для учня
Дві кнопки: надіслати готовий файл або створити (фото камерою / запис з мікрофона) прямо в браузері.

## Як перевіряються відповіді
Вручну: три медалі (золото / срібло / бронза) + фідбек з форматуванням; у віртуальному класі або пізніше в результатах. **У віртуальному класі учень файл додати не може**, лише при самостійному проходженні (домашнє).

## Зображення та аудіо
Фото jpg/png або аудіо.

## Типові помилки
- Ставити на синхронний онлайн-урок (учень не зможе надіслати).

## Контрольний список
- [ ] використовується в домашньому/самостійному проходженні
- [ ] чітке завдання + критерії

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
