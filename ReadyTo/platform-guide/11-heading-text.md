# 11. Заголовок / Текст

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 (імпорт + створення) → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/heading-text
> Маркер масового імпорту: `#Text`
> Оновлено: 2026-11-09

## Призначення
Текстовий блок: пояснення правила, вступ, підсумок, інструкція, текст для читання.

## Для яких навчальних цілей
grammar boxes, пояснення лексики, reading texts, інструкції, підсумки.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Заголовок / Текст».
2. Заголовок і Опис; для кожного свій Розмір (Великий/Середній/Малий) і Вирівнювання.
3. «Стиль блоку»: Без виділення, Інфо, Порада, Увага, Успіх, Особливий (7 кольорів, 9 іконок).
4. «Зберегти».

## Поля
Заголовок · Опис (повне форматування: жирний, курсив, колір, виділення, списки, посилання, індекси, текст у 1–4 колонки) · Стиль блоку.

## Точний синтаксис
- `#Text: Заголовок` + текст рядками. ✅ DOCUMENTED
- Стиль рамки: `| tip`, `| info`, `| warning` у кінці заголовка. ✅
- Стилі «Успіх» і «Особливий» через імпорт не задаються → вручну.

## Формат масового імпорту
```
#Text: Заголовок | tip
Текст пояснення.
```

## Приклад готового завдання
```
#Text: Past Simple: regular verbs | tip
We add -ed to regular verbs: play → played, watch → watched.
If a verb ends in -e, add -d: like → liked.
```

## Як виглядає для учня
Готова плашка з іконкою, кольором і форматуванням. На мобільних колонки стають однією.

## Як перевіряються відповіді
Не перевіряється.

## Зображення та аудіо
Немає (для картинок — блок «Картинка»).

## Типові помилки
- Довгі суцільні абзаци → розбивайте, використовуйте колонки для прикладів.
- Стиль, не з `tip/info/warning`, в імпорті.
