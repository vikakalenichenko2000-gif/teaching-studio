# 22. Колаж

## Призначення
Кілька зображень одним блоком: рівна сітка, мозаїка або вільне полотно.

## Для яких навчальних цілей
Spot the difference, Find something, Describe the picture, Compare and contrast, повторення лексики.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Колаж».
2. «Клікніть або перетягніть» — можна кілька файлів; або вставка з буфера; підпис під кожною (опц.).
3. Режим: **Сітка** (2–5 колонок; 16:9, 4:3, 1:1, 3:4) · **Мозаїка** (плитки 1×1, 2×1, 1×2, 2×2; «Розкласти автоматично») · **Вільний** (полотно, поворот, шари, колір фону).
4. Спільне: відступи 0/6/12/20 px, заокруглення 0/8/16 px, **Нумерація**.
5. Область показу — подвійний клік по картинці.
6. «Зберегти».

## Поля
Заголовок · Опис · картинки (JPEG/PNG, мінімум 2) · підписи · режим · відступи · кути · нумерація.

## Як виглядає для учня
Усі картинки одночасно; клік — на весь екран, стрілки ‹ › у порядку читання. **Немає** режиму презентації й малювання (для цього — Галерея або Картинка).

## Як перевіряються відповіді
Не перевіряється.

## Зображення та аудіо
Лише JPEG/PNG, ≥2 картинки. Оригінали по кліку (>1 MB — повільніше).

## Типові помилки
- Одна картинка → не збережеться.
- Потрібне малювання на уроці → беріть Галерею/Картинку.
- Для говоріння вмикайте **Нумерацію**: «Look at picture 3».
