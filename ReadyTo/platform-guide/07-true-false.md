# 07. Оберіть True чи False

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест: ще ні → **DOCUMENTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/true-false
> Маркер масового імпорту: `#TrueFalse`
> Оновлено: 2026-11-09

## Призначення
Учень оцінює твердження кнопками: True/False або будь-якими власними (Right/Wrong, Так/Ні, імена персонажів…).

## Для яких навчальних цілей
reading/listening comprehension, лексика, загальні знання, grammar awareness (correct/incorrect).

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Оберіть True чи False».
2. Твердження → обрати під ним правильну кнопку.
3. «Налаштування» → «Варіанти відповіді»: перейменувати кнопки / «+ додати варіант» (однакові для всієї вправи).
4. «Зберегти».

## Поля
Заголовок · Опис · Опціональний текст · твердження · «Варіанти відповіді» · «Зображення»/«Аудіо» · «Розкладка» 1–2.

## Точний синтаксис
- Рядок: `Твердження. | Відповідь`. ✅ DOCUMENTED
- Кнопки задаються в заголовку: `#TrueFalse: Заголовок | Right / Wrong / Depends`. Без `|` — True / False.
- Кнопок може бути більше двох.
- ❌ Формат `Penguins can fly. [False]` **не** документований, використовуйте `| False`.
- Імпорт усередині вправи: лише твердження, відповіді обираються після.

## Формат масового імпорту
```
#TrueFalse: Заголовок
Твердження. | True
Твердження. | False
```

## Приклад готового завдання
```
#TrueFalse: Read the text. True or false?
Penguins can fly. | False
People usually sleep in tents when they go camping. | True
Tom went to the cinema with his sister. | True
The film was boring. | False
```

## Як виглядає для учня
Під кожним твердженням кнопки; «Перевірити» показує правильні й неправильні, можна змінити.

## Як перевіряються відповіді
Автоматична, після «Перевірити».

## Зображення та аудіо
На панелі «Налаштування» є перемикачі «Зображення» та «Аудіо» (до кожного рядка). Принцип «все або нічого»: якщо перемикач увімкнено, а до якогось рядка медіа не додано, вправа не збережеться. Картинки jpg/png, кадрування через «Налаштувати область показу». Через масовий імпорт медіа НЕ додається: лише вручну після створення.

## Типові помилки
- «Напівправдиві» твердження.
- Відповідь не збігається з назвою кнопки (`| false` vs `False`, ⚠️ регістр перевірити тестом).
- Баланс: ≈ порівну True і False.

## Контрольний список
- [ ] кожен рядок закінчується `| Кнопка`
- [ ] назва кнопки точно як у заголовку
- [ ] однозначні твердження
- [ ] баланс відповідей

---
