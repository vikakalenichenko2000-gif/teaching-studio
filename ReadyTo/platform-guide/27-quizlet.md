## Призначення
Набір карток Quizlet, вбудований в урок як віджет.

## Для яких навчальних цілей
тренування лексики без виходу з уроку.

## Покрокове створення в редакторі
1. Відкрийте набір на quizlet.com → скопіюйте посилання з адресного рядка.
2. «Додати новий елемент» → «Quizlet» → «Посилання на Quizlet».
3. «Зберегти».

## Поля
Заголовок · Опис · Посилання на Quizlet.

## Точний синтаксис
Маркера немає → вручну. Набір **публічний**. Набори готую в `teaching/Quizlet/imports/` (Term<TAB>Definition).

## Формат масового імпорту
```
Немає.
```

## Приклад готового завдання
```
Посилання: https://quizlet.com/ua/1206489076/unit-8-flash-cards/ (ваш набір)
```

## Як виглядає для учня
Віджет у уроці; режими (Картки, Підбір, Заучування, Тест, Правопис) у нижньому куточку; «Переглянути модуль» відкриває Quizlet.

## Як перевіряються відповіді
Результати **не зберігаються**, у віртуальному класі не синхронізується. Для статистики по словах — рідний блок «Словник» (файл 19).
