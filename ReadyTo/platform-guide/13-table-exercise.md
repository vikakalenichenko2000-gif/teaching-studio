# 13. Таблиця / Таблиця-вправа

> **Статус:** Сторінка: ⏳ · Імпорт: не підтверджено → **UNVERIFIED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/table
> Маркер масового імпорту: немає (лише вручну)
> Оновлено: 2026-11-09

## Призначення
Таблиця в уроці (заливка, об'єднання клітинок, картинки, вставка з Excel, «шторка»). Один перемикач робить з неї вправу з пропусками.

## Для яких навчальних цілей
структурована інформація (граматичні таблиці, розклад), а у режимі вправи — завдання на оцінку з пропусками в клітинках.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Таблиця». ⏳ Решта — на сторінці блоку.

## Поля
⏳

## Точний синтаксис
- Пропуски у клітинках — як у «Заповніть пропуск»: `[слово]`, варіанти через `/`, вільний `[*]`, кілька пропусків в одній клітинці. ✅ (з порівняльної таблиці в документації «Заповніть таблицю»)
- Вставка з Excel. ✅
- ⚠️ Окремого маркера в масовому імпорті не видно (`#Table` найімовірніше створює «Заповніть таблицю», див. файл 08). Ймовірно, лише вручну — перевірити.

## Формат масового імпорту
```
⚠️ Не підтверджено. Вручну: створіть таблицю в Excel/Google Sheets → скопіюйте → вставте в редактор → у клітинках поставте [ ].
```

## Приклад готового завдання
```
| Present | Past |
|---|---|
| go | [went] |
| see | [saw] |
| eat | [ate] |
```

## Як виглядає для учня
Таблиця з полями в клітинках (у режимі вправи). ⏳

## Як перевіряються відповіді
Як у «Заповніть пропуск»: оцінка, статистика, історія відповідей. ✅

## Зображення та аудіо
Картинки в клітинках ✅. ⏳ Сторінку цього блоку ще не прочитано (сайт обмежує частоту запитів). Розділ доповню, коли вона завантажиться.

## Типові помилки
- Плутати з «Заповніть таблицю» (там тренажер без збереження результатів).

## Контрольний список
- [ ] обрано правильний блок: оцінка → Таблиця-вправа, тренування → Заповніть таблицю
