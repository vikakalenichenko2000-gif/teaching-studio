# 24. Кнопка (посилання)

> **Статус:** Сторінка: ✅ · Імпорт: ❌ → вручну
> Офіційна документація: https://readyto.net/docs/lesson-blocks/button-link
> Маркер масового імпорту: немає (лише вручну)
> Оновлено: 2026-11-09

## Призначення
Кнопка на зовнішній ресурс (нова вкладка).

## Для яких навчальних цілей
Google Drive, Notion, форми, Baamboozle, Wordwall як посилання, інші сайти.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Кнопка (посилання)».
2. «Назва на кнопці».
3. «Посилання» — має починатися з `https://`.
4. «Зберегти».

## Поля
Заголовок · Опис · Назва на кнопці · Посилання.

## Точний синтаксис
Маркера немає → вручну. URL лише реальний, з `https://`.

## Формат масового імпорту
```
Немає.
```

## Приклад готового завдання
```
Назва: Play the vocabulary game · Посилання: (реальне посилання на створену гру)
```

## Як виглядає для учня
Заголовок + кнопка; урок лишається відкритим.

## Як перевіряються відповіді
Не перевіряється.

—

## Типові помилки
- `http://` або без протоколу → не збережеться.
- Вигаданий URL.

## Контрольний список
- [ ] https://
- [ ] посилання відкривається без входу (якщо це потрібно учням)
