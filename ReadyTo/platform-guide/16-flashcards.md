# 16. Фліп-картки

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 (імпорт + створення) → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/speaking-cards
> Маркер масового імпорту: `#FlipCards`
> Оновлено: 2026-11-09

## Призначення
Колода карток із лицем і зворотом (картинка, текст). Для говоріння, лексики, рольових ігор.

## Для яких навчальних цілей
speaking prompts, лексика (слово ↔ переклад), питання ↔ відповідь, картинка ↔ назва, корисні фрази.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Фліп-картки».
2. «Текст картки» → «Додати ще» (порядок — перетягуванням за ручку).
3. Налаштування: «Колір карток» (8 + піпетка), «Зображення на картках», «Зворотний бік карток».
4. «Зберегти».

## Поля
Заголовок · Опис · Опціональний текст · текст картки · зворот (багаторядковий) · картинка · колір.

## Точний синтаксис
- `Лице <Зворот>`; зворот може бути багаторядковим. ✅ DOCUMENTED
- Якщо хоч одна картка має `<...>` — його мають мати **всі**. ✅

## Формат масового імпорту
```
#FlipCards: Заголовок
Лице 1 <Зворот 1>
Лице 2 <Зворот 2>
```

## Приклад готового завдання
```
#FlipCards: Talk about your holidays.
Where did you go last summer? <I went to… / We visited…>
Who did you travel with? <I travelled with my family / friends.>
What was the best day? <The best day was when…>
```

## Як виглядає для учня
Сітка карток з номерами; кнопка-перегортання в кутку. Клік по картці — повноекранний режим для класу (‹ › або ← →, Esc).

## Як перевіряються відповіді
Автоматичної перевірки немає (оцінює вчитель усно).

## Зображення та аудіо
«Зображення на картках»: «Змінити» (файл) або вставка з буфера; кадрування. Принцип «все або нічого» для картинок і звороту. Картинки — вручну після імпорту.

## Типові помилки
- Зворот лише в частині карток → помилка.
- Задовгий текст на лицьовому боці.

## Контрольний список
- [ ] звороти в усіх або в жодній
- [ ] короткі формулювання
- [ ] для молодших — з картинками

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
