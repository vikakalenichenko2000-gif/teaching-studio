# 03. Оберіть правильний варіант (a, b, c)

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 (імпорт + створення) → **TESTED** (кілька питань через порожній рядок = один блок ✅)
> Офіційна документація: https://readyto.net/docs/lesson-blocks/multiple-choice
> Маркер масового імпорту: `#MultipleChoice`
> Оновлено: 2026-11-09

## Призначення
Питання з варіантами: один, кілька або всі правильні.

## Для яких навчальних цілей
grammar quizzes, reading/listening comprehension, лексика, міні-тест наприкінці уроку.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Оберіть правильний варіант».
2. Питання → під ним варіанти («+ Додати опцію» або Enter).
3. Позначте галочкою правильні.
4. «Додати ще» — наступне питання.
5. «Зберегти».

## Поля
Заголовок · Опис · Опціональний текст · питання · варіанти · «Не перемішувати варіанти» · «Зображення»/«Аудіо» до кожного питання · «Розкладка» 1–4 (з медіа 1–2).

## Точний синтаксис
- Перший рядок групи — питання, далі варіанти по рядку.
- `*` на початку варіанта = правильна відповідь; можна кілька `*`. ✅ DOCUMENTED
- Питання розділяйте порожнім рядком: в одному блоці може бути кілька питань. ✅ TESTED 2026-11-09
- **Не** пишіть `a) b) c)`: платформа перемішує варіанти.
- Формат `[correct/wrong/wrong]` тут **не** використовується.

## Формат масового імпорту
```
#MultipleChoice: Заголовок
Питання?
*правильний
неправильний
неправильний

Наступне питання?
...
```

## Приклад готового завдання
```
#MultipleChoice: Read the story and choose the correct answer.
Where did Tom go yesterday?
To school.
*To the cinema.
To the hospital.

Who did he go with?
*His sister.
His teacher.
His grandmother.
```

## Як виглядає для учня
Як у редакторі. Варіанти перемішуються при кожному оновленні (якщо не ввімкнено «Не перемішувати»). У віртуальному класі порядок у вас і в учнів може різнитися.

## Як перевіряються відповіді
«Перевірити» — лише коли є відповідь на кожне питання. Зелений/червоний, можна переобрати. Після оновлення сторінки — медалька 🥇🥈🥉 залежно від кількості правильних.

## Зображення та аудіо
На панелі «Налаштування» є перемикачі «Зображення» та «Аудіо» (до кожного рядка). Принцип «все або нічого»: якщо перемикач увімкнено, а до якогось рядка медіа не додано, вправа не збережеться. Картинки jpg/png, кадрування через «Налаштувати область показу». Через масовий імпорт медіа НЕ додається: лише вручну після створення.

## Типові помилки
- Немає жодної `*` → помилка.
- Два «майже правильні» варіанти → неоднозначність.
- «All of the above» при перемішуванні втрачає сенс → увімкніть «Не перемішувати» вручну.

## Контрольний список
- [ ] у кожного питання ≥1 `*`
- [ ] 3–4 варіанти, дистрактори правдоподібні
- [ ] без a) b) c)
- [ ] одна однозначна відповідь (якщо не задумано кілька)
