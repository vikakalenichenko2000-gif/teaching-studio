# 01. Заповніть пропуск

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/fill-blanks
> Маркер масового імпорту: `#GapFill`
> Оновлено: 2026-11-09

## Призначення
Учень сам вписує пропущене слово чи форму. Найсильніша перевірка: треба згадати, а не впізнати.

## Для яких навчальних цілей
граматичні часи й форми дієслів; артиклі, прийменники; лексика на етапі «вже знаю»; сталі вирази. Не для першого знайомства зі словами (тоді DragWords або DropDown).

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Заповніть пропуск».
2. Заголовок (завдання), за потреби опис.
3. У «Вміст вправи» впишіть речення, слово-відповідь візьміть у [ ] (або виділіть і натисніть кнопку [ ]).
4. «Додати ще» для наступного речення.
5. «Зберегти».

## Поля
Заголовок · Опис · Опціональний текст · речення з пропусками · «Зображення»/«Аудіо» (до кожного речення) · «Розкладка» 1–4 (з медіа 1–2).

## Точний синтаксис
- `[відповідь]` — пропуск; учень бачить порожнє поле. ✅
- `[a/b]` — усі варіанти правильні: `I [am/'m] Kate.` ✅ TESTED
- `[*]` — **вільний пропуск**: будь-яка відповідь завжди зараховується (ім'я, вік, відповідь про себе). ✅ DOCUMENTED
- **Регістр не має значення**: `[What is it]` = «what is it». ✅
- Підказка в круглих дужках `(go)` — звичайний текст.
- `| text` / `| dialogue` у заголовку → суцільний текст/діалог; рядки без пропусків дозволені; порожній рядок — новий текст. ✅
- Без `| text` кожен рядок має містити пропуск (інструкцію без пропуску імпорт перенесе в опис).
- Той самий синтаксис працює в «Таблиці-вправі» (пропуски в клітинках).

## Формат масового імпорту
```
#GapFill: Заголовок
+Опис
++Опціональний текст
речення з [відповіддю]
...
```

## Приклад готового завдання
```
#GapFill: Complete the sentences with the correct form of the verbs.
+Use Past Simple.
I [went] to school yesterday. (go)
She [was] at home on Sunday. (be)
They [played] football after school. (play)
We [didn't watch/did not watch] TV last night. (not watch)
```

## Як виглядає для учня
Порожні поля замість дужок; відповіді в дужках бачите лише ви в редакторі. «Перевірити» → правильні/неправильні, можна виправити й перевірити ще раз.

## Як перевіряються відповіді
Автоматично; регістр не враховується; зараховуються всі варіанти з `[a/b]`; `[*]` — завжди правильно. ⚠️ Апострофи (’ vs ') і зайві пробіли — перевірити тестом.

## Зображення та аудіо
Перемикачі «Зображення» та «Аудіо» (до кожного речення), «все або нічого». Розкладка з медіа — 1 або 2 колонки. Медіа — вручну після імпорту.

## Типові помилки
- Лише одна відповідь там, де природно приймаються кілька (`didn't / did not`, `'s / is`) → додайте `/`.
- Пропуск, який можна заповнити кількома словами за змістом → додайте підказку (дієслово в дужках).
- Окрема копія речення з `____` не потрібна, платформа сама робить пропуск.

## Контрольний список
- [ ] кожен рядок має `[ ]` (або в заголовку `| text`)
- [ ] усі прийнятні варіанти через `/`
- [ ] підказки в `( )` після речення
- [ ] граматика й рівень перевірені
