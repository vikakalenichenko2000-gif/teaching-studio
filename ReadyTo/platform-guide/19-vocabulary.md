# 19. Словник

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 (імпорт + створення) → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/vocabulary
> Маркер масового імпорту: `#Vocabulary`
> Оновлено: 2026-11-09

## Призначення
Міні-тренажер: список слів із перекладом → платформа сама будує 5 режимів практики (Картки, Зʼєднати, Написати, Вибір, Тест) і веде статистику по кожному слову. **Єдиний тренажер, що зберігає результати.**

## Для яких навчальних цілей
подання й тренування нової лексики; домашнє повторення зі статистикою (замість Quizlet, коли потрібні результати).

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Словник».
2. Слово — ліве поле, переклад — праве; Enter або «Додати ще».
3. «Налаштування» → «До кожного слова»: Зображення / Аудіо / Опис.
4. «Додаткові налаштування» → Нумерація.
5. «Зберегти».

## Поля
Заголовок · Опис · слово · переклад · (опційно) зображення, аудіо, опис із форматуванням · нумерація. Порядок — перетягуванням за ручку.

## Точний синтаксис
- Масовий імпорт: `слово — переклад` (довге тире з пробілами). ✅ DOCUMENTED
- `<опис>` після пари: приклад, транскрипція, пояснення; може бути багаторядковим. ✅
- Імпорт усередині вправи: слово і переклад через **таб або тире**, по одному на рядок (без описів).

## Формат масового імпорту
```
#Vocabulary: Заголовок
word — переклад <Example sentence.>
```

## Приклад готового завдання
```
#Vocabulary: Holiday words
go camping — відпочивати з наметами <We go camping every summer.>
go hiking — ходити в похід <They go hiking in the mountains.>
get lost — заблукати <Don't get lost in the forest!>
```

## Як виглядає для учня
Список слів з перекладом (+ картинка, кнопка-динамік, опис). Кнопка «Практика»:
- **Картки** — переворот кліком, «Знаю» / «Не знаю».
- **Зʼєднати** — Слово↔Переклад або Слово↔Картинка (якщо є картинки).
- **Написати** — з перекладу або з аудіо (якщо є аудіо); регістр не рахується, зайві пробіли прибираються.
- **Вибір** — обрати правильний переклад.
- **Тест** — повзунок 2…усі слова, змішані типи; вивчене слово = ≥75%; «Повторити складні» / «Новий тест». Мінімум 2 слова; незавершений тест не зараховується.

## Як перевіряються відповіді
Автоматично в усіх режимах. **Результати зберігаються**: «Результат тренажера» — прогрес по словах (проблемні зверху, «Потребують повторення») і середній результат по кожному режиму й тесту. У віртуальному класі не синхронізується (самостійна робота).

## Зображення та аудіо
Перемикачі «Зображення» / «Аудіо» / «Опис» — для всіх рядків (все або нічого для картинок і аудіо). Картинки: файл або вставка з буфера, кадрування. **Аудіо можна записати прямо в редакторі кнопкою-мікрофоном** (ваша вимова) або завантажити файл. Медіа додаються вручну після імпорту.

## Типові помилки
- Дефіс замість ` — ` у масовому імпорті.
- Кілька синонімів у перекладі (ваше правило: один переклад).
- Один величезний словник на все: документація радить окремий словник на кожну тему, так статистика читабельніша.

## Контрольний список
- [ ] ` — ` з пробілами
- [ ] переклад одним словом/виразом
- [ ] приклад у `<...>` на рівні учнів
- [ ] окремий словник на тему
- [ ] для молодших — картинки й аудіо (запис голосом у редакторі)
