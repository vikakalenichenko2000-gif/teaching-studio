# 08. Заповніть таблицю

> **Статус:** Сторінка: ✅ · Імпорт: **DOCUMENTED** (відповідність маркера — UNVERIFIED) · Тест: ще ні
> Офіційна документація: https://readyto.net/docs/lesson-blocks/three-columns
> Маркер масового імпорту: `#Table`
> Оновлено: 2026-11-09

## Призначення
Вправа-**тренажер**: таблиця на 2–4 колонки; система щоразу випадково ховає різні клітинки.

## Для яких навчальних цілей
irregular verbs (infinitive / past / participle), adjective / comparative / superlative, word / translation, однина/множина.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Заповніть таблицю».
2. «Кількість колонок» 2–4.
3. Кожен рядок: слова через кому (`go, went, gone`); **впишіть таблицю повністю**, система сама вирішує, що сховати.
4. «Назви колонок» (Додаткові налаштування) — рядок заголовків.
5. «Зберегти».

## Поля
Заголовок · Опис · рядки таблиці · «Кількість колонок» 2–4 · «Назви колонок».

## Точний синтаксис
- Колонки через кому, варіанти в клітинці через `/`: `dream, dreamt/dreamed, dreamt/dreamed`. ✅ DOCUMENTED
- Масовий імпорт: `#Table: Заголовок | Назва1, Назва2, Назва3` + рядки; 2–4 колонки; назви необов'язкові. ✅
- ⚠️ Маркер у масовому імпорті один — `#Table`. Приклад з документації (неправильні дієслова, 2–4 колонки, коми) відповідає саме цьому блоку, але чи створює `#Table` «Заповніть таблицю», а не «Таблицю-вправу», — **перевірити тестом**.

## Формат масового імпорту
```
#Table: Irregular verbs | Infinitive, Past Simple, Past Participle
go, went, gone
see, saw, seen
```

## Приклад готового завдання
```
#Table: Irregular verbs | Infinitive, Past Simple, Past Participle
+Training: different words are hidden every time. Results are not saved.
go, went, gone
see, saw, seen
eat, ate, eaten
write, wrote, written
get, got, got/gotten
```

## Як виглядає для учня
Частина клітинок порожня, решта — підказки. Після заповнення «Перевірити».

## Як перевіряються відповіді
Автоматична, але **результати НЕ зберігаються** і не йдуть у статистику; після оновлення сторінки все зникає. Пропуски щоразу інші → можна проходити багато разів. Документація радить попередити учня в описі.

## Зображення та аудіо
Не описано (зображень/аудіо немає).

## Типові помилки
- Кома всередині клітинки ламає колонки.
- Використовувати як завдання на оцінку (для оцінки беріть «Таблицю-вправу», файл 13).
- Різна кількість клітинок у рядках.

## Контрольний список

- [ ] варіанти через `/`
- [ ] в описі: «результати не зберігаються»
- [ ] таблиця заповнена повністю
