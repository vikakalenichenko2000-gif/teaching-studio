# 14. Сортування за колонками

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест: ще ні → **DOCUMENTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/column-sort
> Маркер масового імпорту: `#ColumnSort`
> Оновлено: 2026-11-09

## Призначення
Учень перетягує слова у потрібні колонки (будь-яка кількість колонок).

## Для яких навчальних цілей
частини мови, regular/irregular verbs, countable/uncountable, категорії лексики, positive/negative adjectives, звуки (/s/, /z/, /ɪz/).

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Сортування за колонками».
2. «Назва колонки» → слова (Enter або «Додати слово»).
3. «Додати колонку» → повторити.
4. За потреби «Лічильник слів» (Додаткові налаштування).
5. «Зберегти».

## Поля
Заголовок · Опис · колонки (назва ≤34 символи + слова) · «Розкладка» 2/3/4 · «Лічильник слів».

## Точний синтаксис
- Група: перший рядок — назва колонки, далі елементи; групи розділяє порожній рядок. ✅ DOCUMENTED
- Мінімум 2 колонки; у кожної назва і ≥1 слово; назва ≤34 символи. ✅

## Формат масового імпорту
```
#ColumnSort: Заголовок
Колонка 1
слово
слово

Колонка 2
слово
```

## Приклад готового завдання
```
#ColumnSort: Sort the verbs.
Regular verbs
played
watched
visited

Irregular verbs
went
saw
ate
```

## Як виглядає для учня
«Слова для розподілу» зверху (перемішані, замочок закріплює), під ними порожні колонки.

## Як перевіряються відповіді
«Перевірити» лише коли всі слова розподілені («Спочатку розмістіть усі слова по колонках!»). Зелений/червоний, можна переставити.

## Зображення та аудіо
Не описано (лише текст).

## Типові помилки
- Слово, що підходить до двох колонок.
- Назва колонки довша за 34 символи.
- Не плутати з «Заповніть таблицю».

## Контрольний список
- [ ] категорії взаємовиключні
- [ ] ≥2 колонки, назви ≤34 символи
- [ ] порожній рядок між колонками
