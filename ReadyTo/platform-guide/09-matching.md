# 09. З'єднайте елементи

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест: ще ні → **DOCUMENTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/matching
> Маркер масового імпорту: `#Matching`
> Оновлено: 2026-11-09

## Призначення
Пари текст-текст або картинка-текст. Перевірка одразу, без кнопки.

## Для яких навчальних цілей
переклади, визначення, синоніми/антоніми, question–answer, picture matching (молодші учні).

## Покрокове створення в редакторі
1. «Додати новий елемент» → «З'єднайте елементи».
2. «Тип завдання»: «Картинка-текст» або «Текст-текст».
3. Картинка-текст: «Обрати файл» (jpg/png ≤5 MB) + текст поруч; кадрування кліком по картинці.
4. Текст-текст: лівий елемент і відповідник.
5. «Додати ще» / «Імпорт зі списку» (пари по рядку, розділювач — таб або тире).
6. «Зберегти».

## Поля
Заголовок · Опис · Опціональний текст · «Тип завдання» · пари.

## Точний синтаксис
- Масовий імпорт: `ліве — праве`, **довге тире з пробілами**. Дефіс усередині слова (`T-shirt`) не заважає. ✅ DOCUMENTED
- Імпорт усередині вправи: таб або тире.
- Масовим імпортом створюється текст-текст; картинки — вручну. ⚠️

## Формат масового імпорту
```
#Matching: Заголовок
go hiking — ходити в похід
get lost — заблукати
```

## Приклад готового завдання
```
#Matching: Match the phrases with the translations.
go hiking — ходити в похід
go camping — відпочивати з наметами
go cycling — кататися на велосипеді
get lost — заблукати
```

## Як виглядає для учня
Текст-текст: ліва колонка у вашому порядку, права перемішується при кожному оновленні. Картинка-текст: картинки у вашому порядку, слова перемішані над ними. Лупа відкриває картинку на весь екран.

## Як перевіряються відповіді
У реальному часі: правильна пара зелена, неправильна червона. Після завершення — «Пройти ще раз» (перетасовує).

## Зображення та аудіо
Лише в типі «Картинка-текст»: jpg/png до 5 MB, усі картинки в однаковій горизонтальній рамці, кадрування. Аудіо не описано.

## Типові помилки
- Дефіс ` - ` замість ` — ` у масовому імпорті.
- Однакові відповідники (два «ходити»).
- Синоніми, що підходять до кількох лівих елементів.

## Контрольний список
- [ ] ` — ` з пробілами
- [ ] кожна пара однозначна, праві елементи унікальні
- [ ] 6–10 пар

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
