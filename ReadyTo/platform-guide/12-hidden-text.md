# 12. Прихований текст

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ⏳ · Тест на платформі: ✅ 2026-11-09 (імпорт + створення) → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/hidden-text
> Маркер масового імпорту: `#HiddenText`
> Оновлено: 2026-11-09

## Призначення
Текст, що відкривається по кліку: підказки, відповіді, переклади. З нумерацією кроків і замочком для онлайн-уроку.

## Для яких навчальних цілей
загадки (підказки по черзі), граматичні підказки, самоперевірка, відповіді після обговорення, переклад.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Прихований текст». ⏳ Поля редактора — на сторінці блоку.
2. «Зберегти».

## Поля
⏳

## Точний синтаксис
- `=Напис на кнопці` — крок; рядки під ним — прихований текст. ✅ DOCUMENTED
- Кожен `=` має мати під собою текст. ✅
- Замочок для онлайн-уроку (керування доступом) — ⏳ деталі.

## Формат масового імпорту
```
#HiddenText: Заголовок
=Кнопка 1
Прихований текст 1
=Кнопка 2
Прихований текст 2
```

## Приклад готового завдання
```
#HiddenText: What animal is it?
=Hint 1
It lives in cold places.
=Hint 2
It is black and white.
=Answer
A penguin.
```

## Як виглядає для учня
Кнопки кроків; клік відкриває текст. ⏳

## Як перевіряються відповіді
Не перевіряється.

## Зображення та аудіо
⏳ Сторінку цього блоку ще не прочитано (сайт обмежує частоту запитів). Розділ доповню, коли вона завантажиться.

## Типові помилки
- `=` без тексту під ним → помилка.
- Відповідь видно в заголовку.

## Контрольний список
- [ ] під кожним `=` є текст
- [ ] заголовок не розкриває відповідь
