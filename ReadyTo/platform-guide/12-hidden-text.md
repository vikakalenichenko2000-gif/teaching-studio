# 12. Прихований текст

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка: ✅ · Тест на платформі: ✅ 2026-11-09 → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/hidden-text
> Маркер масового імпорту: `#HiddenText`
> Оновлено: 2026-11-09

## Призначення
Текст, що відкривається по кліку: підказки, відповіді, переклади. З нумерацією кроків і замочком для онлайн-уроку.

## Для яких навчальних цілей
загадки (підказки по черзі), граматичні підказки, самоперевірка, відповіді після обговорення, переклад.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Прихований текст».
2. Заголовок і опис — необов'язкові.
3. Кожен крок: «Видимий текст» (підпис рядка) + «Прихований текст» (повне форматування); обидва обов'язкові. «Додати ще» для нових кроків.
4. «Нумерувати кроки» — бейджі з номерами.
5. Замочок на кроці → учень не відкриє, доки ви не розблокуєте на онлайн-уроці.
6. «Зберегти».

## Поля
Заголовок (необов.) · Опис (необов.) · кроки (видимий + прихований текст) · «Нумерувати кроки» · замочок на кожному кроці.

## Точний синтаксис
- `=Видимий текст` + рядки під ним = прихований текст. ✅ TESTED
- Під кожним `=` має бути текст.
- Замочок і нумерація — лише вручну в редакторі (у синтаксисі імпорту не описані).

## Формат масового імпорту
```
#HiddenText: Заголовок
=Кнопка 1
Прихований текст 1
=Кнопка 2
Прихований текст 2
```

## Приклад готового завдання
```
#HiddenText: What animal is it?
=Hint 1
It lives in cold places.
=Hint 2
It is black and white.
=Answer
A penguin.
```

## Як виглядає для учня
Рядки зі стрілкою; клік розкриває текст, повторний — згортає; кроки незалежні. Заблоковані — зі значком замка.

## Як перевіряються відповіді
Не перевіряється. **Замочок**: на онлайн-уроці клік по замку у вашому фреймі відкриває крок усім учням миттєво; розблокування діє лише в поточному запуску уроку.

## Зображення та аудіо
Немає окремих медіа-полів (прихований текст має повне форматування).

## Типові помилки
- `=` без тексту під ним.
- Відповідь видно в заголовку.
- Забули замочок на «Answer» для онлайн-уроку.

## Контрольний список
- [ ] під кожним `=` є текст
- [ ] заголовок не розкриває відповідь

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
