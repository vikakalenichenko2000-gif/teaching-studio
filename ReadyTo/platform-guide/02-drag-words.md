# 02. Перетягніть слова

> **Статус:** Імпорт: **DOCUMENTED** · Сторінка блоку: ✅ прочитано · Тест на платформі: ✅ 2026-11-09 (імпорт + створення) → **TESTED**
> Офіційна документація: https://readyto.net/docs/lesson-blocks/drag-words
> Маркер масового імпорту: `#DragWords`
> Оновлено: 2026-11-09

## Призначення
Учень перетягує слова з банку в пропуски. Впізнавання замість згадування.

## Для яких навчальних цілей
нова лексика; прості структури (am/is/are); молодші й слабші учні; перше знайомство з темою.

## Покрокове створення в редакторі
1. «Додати новий елемент» → «Перетягніть слова».
2. Заголовок, опис.
3. Речення, слово-відповідь у [ ] (або кнопка [ ]).
4. «Налаштування» → поле «Зайві слова»: слова-пастки через кому.
5. «Додати ще» або «Імпорт зі списку» всередині вправи (речення по одному на рядок).
6. «Зберегти».

## Поля
Заголовок · Опис · Опціональний текст · речення · «Зайві слова» · перемикачі «Зображення»/«Аудіо» · «Розкладка» 1–4 колонки (з медіа — 1 або 2).

## Точний синтаксис
- `[слово]` — у дужках рівно **одне** слово; `/` і `[*]` **не підтримуються**. ✅ DOCUMENTED
- `~слово1, слово2` — окремий рядок із зайвими словами для банку. ✅
- `| text` / `| dialogue` у заголовку — суцільний текст. ✅
- Банк слів спільний для всієї вправи.
- Індекси: `H_2O` → H₂O, `x^2` → x².

## Формат масового імпорту
```
#DragWords: Заголовок
~пастка1, пастка2
речення з [словом]
...
```

## Приклад готового завдання
```
#DragWords: Complete with am, is or are.
~was, be
I [am] eight years old.
She [is] my sister.
They [are] my friends.
```

## Як виглядає для учня
Зверху перемішаний банк слів, нижче речення з пропусками. Можна тягнути мишкою, пальцем або клік на слово → клік на пропуск. Замочок у куті банку закріплює його під час прокручування.

## Як перевіряються відповіді
«Перевірити» активна, коли всі пропуски заповнені. Правильні зелені, неправильні червоні. Біля пропуску — «крапки історії» (3 останні спроби). Після 3 невдалих спроб — «Показати відповіді». В онлайн-уроці ви бачите кольори наживо ще до перевірки; «Пройти ще раз» скидає відповіді всього класу.

## Зображення та аудіо
На панелі «Налаштування» є перемикачі «Зображення» та «Аудіо» (до кожного рядка). Принцип «все або нічого»: якщо перемикач увімкнено, а до якогось рядка медіа не додано, вправа не збережеться. Картинки jpg/png, кадрування через «Налаштувати область показу». Через масовий імпорт медіа НЕ додається: лише вручну після створення.

## Типові помилки
- `[am/'m]` → помилка імпорту (для варіантів беріть GapFill).
- Зайве слово, яке насправді підходить до пропуску.
- Однакові слова-відповіді в кількох реченнях дають неоднозначність, краще різні.

## Контрольний список
- [ ] у кожних дужках одне слово, без /
- [ ] зайві слова не підходять до жодного пропуску
- [ ] 2–4 пастки для старших, 0–2 для молодших
- [ ] з медіа: картинка/аудіо до КОЖНОГО речення

---
Зміни зберігає лише кнопка «Зберегти»: «Закрити» або клік поза вікном їх втрачає.
