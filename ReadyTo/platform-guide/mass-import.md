# Масовий імпорт уроку ReadyTo («Імпорт зі списку (кілька вправ)»)

> **Джерело:** https://readyto.net/docs/lesson-blocks/bulk-import. Дослівна копія: `source/bulk-import-page.md`
> **Статус:** синтаксис — **DOCUMENTED** · **TESTED 2026-11-09**: усі 16 маркерів (файл `../tested/2026-11-09_all-16-types-TESTED.txt`)
> Оновлено: 2026-11-09

## 1. Де кнопка
Урок → внизу, під «Додати новий елемент» і «Копіювати елемент» → широка кнопка **«Імпорт зі списку (кілька вправ)»**.
У вікні: поле тексту (з номерами рядків), посилання «Підказка щодо синтаксису», кнопка «Промпти для ШІ».

## 2. Процес
1. Вставити текст → **«Перевірити»**.
2. Прев'ю всіх блоків. Біля кожної помилки показано рядок, причину і правильний приклад. Клік на «рядок N» ставить курсор на цей рядок.
3. Виправити → «Перевірити» ще раз.
4. Усе зелене → **«Створити вправи»** → сторінка перезавантажиться з блоками.
5. Медіа (картинки, аудіо), розкладку та інші налаштування можна додати вже після створення, у звичайному редакторі.

Дрібні огріхи імпорт виправляє сам і показує їх жовтим у прев'ю. Наприклад, інструкцію без пропуску на початку GapFill він перенесе в опис.

## 3. Як копіювати мій текст
Я завжди даю урок у **блоці коду**. Копіюйте його **кнопкою Copy** у куті рамки, не виділенням мишкою: так не загубляться `<...>`, `*`, `___`. Службові рядки рамки (```) імпорт прибирає сам.
Або відкрийте файл з `ReadyTo/lessons/` і скопіюйте весь вміст.

## 4. Структура

| Елемент | Синтаксис | Примітка |
|---|---|---|
| Початок блоку | `#Тип: Заголовок` | заголовок необов'язковий, його бачить учень |
| Опис | `+текст` | одразу під заголовком |
| Опціональний текст | `++текст` | маленький сірий напис |
| Між блоками | порожній рядок | обов'язково |
| Модифікатор | `#Тип: Заголовок \| …` | кнопки TrueFalse, колонки Table, стиль Text, `text`/`dialogue` |

**16 типів (маркерів):** `Text, Vocabulary, GapFill, DropDown, DragWords, MultipleChoice, TrueFalse, Table, Matching, Unscramble, SortSentences, ColumnSort, FlipCards, Writing, HiddenText, TeacherNote`.

## 5. Спецсимволи
| Символ | Значення |
|---|---|
| `[a/b]` | GapFill: усі варіанти правильні · DropDown: перший правильний |
| `*` | MultipleChoice: правильний варіант (може бути кілька) |
| ` — ` | пара у Vocabulary і Matching (довге тире з пробілами) |
| `<...>` | Vocabulary: опис/приклад · Unscramble: підказка · FlipCards: зворот (може бути багаторядковим) |
| `?` | Writing: питання (на початку рядка) |
| `_` | Unscramble: склеює слова в одну плитку (`every_day`) |
| `\|` | TrueFalse: кнопки · Table: назви колонок · Text: `tip`/`info`/`warning` · GapFill/DropDown/DragWords: `text`/`dialogue` |
| `=` | HiddenText: напис кнопки кроку · SortSentences: заголовок групи |
| `~` | SortSentences: зайве речення · DragWords: зайві слова через кому |

## 6. Правила
- DragWords: в одних дужках одне слово, без `/`.
- FlipCards: якщо зворот `<...>` є хоч в одній картці, він потрібен у всіх.
- Unscramble: якщо підказка `<...>` є хоч в одному рядку, вона потрібна в усіх.
- TrueFalse: без `|` у заголовку кнопки будуть True / False.
- Table: 2–4 колонки, назви необов'язкові.
- `| text` / `| dialogue` у GapFill, DropDown, DragWords: один суцільний текст без номерів, рядки без пропусків дозволені; порожній рядок починає новий текст.
- SortSentences: речення в правильному порядку; тексти розділяє порожній рядок, у кожному ≥2 речень.
- HiddenText: під кожним рядком `=Напис` має бути текст.
- **Заголовок і опис бачить учень**, тож не пишіть там, як працює формат. Варіанти в DropDown і MultipleChoice платформа перемішує сама.
- У курсах `#TeacherNote` стає прихованим текстом із замочком.

## 7. Що НЕ імпортується (лише вручну)
Картинка · Галерея · Колаж · Аудіо · Відео · Відео з YouTube · Кнопка (PDF) · Кнопка (посилання) · Файл учня · WordWall · Quizlet · Genially · Таблиця-вправа (⚠️ ймовірно) · картинки й аудіо всередині вправ · тип «Картинка-текст» у Matching.

## 8. Імпорт усередині однієї вправи (не плутати)
Більшість вправ мають власний «Імпорт зі списку». Формати там дещо інші:
- Matching: пара через **таб або тире**.
- MultipleChoice: питання блоками через порожній рядок, `*` для правильних.
- TrueFalse: лише твердження, відповіді обираєте після.
- Заповніть таблицю: колонки через кому, варіанти через `/`.
- FlipCards: `Лице <Зворот>`.
- ColumnSort: блоки через порожній рядок, перший рядок — назва колонки.

## 9. Мій процес видачі уроку
**Варіант A (основний):** один текст для масового імпорту, лише з підтримуваних маркерів. Перевіряю його `tools/check_import.py` і зберігаю в `ReadyTo/lessons/`.
**Варіант B:** список ручних блоків (медіа, інтеграції, кнопки) з точними налаштуваннями: що додати і після якого блоку.

## 10. Перевірка перед видачею
```
python3 ReadyTo/tools/check_import.py ReadyTo/lessons/<файл>.txt
```
Валідатор перевіряє правила з цієї сторінки: типи, дужки, `*`, ` — `, кнопки TrueFalse, колонки Table, «все або нічого» для `<...>`, порожні рядки між блоками.
Остаточна перевірка — кнопка «Перевірити» в ReadyTo. Блок отримує статус **TESTED**, лише коли викладачка підтвердить, що він створився правильно.
