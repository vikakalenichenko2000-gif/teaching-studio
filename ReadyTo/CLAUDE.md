## Джерела
- Офіційна документація: https://readyto.net/docs/lesson-blocks/ (копії — `platform-guide/source/`).
- Сайт обмежує частоту запитів (429): завантажувати повільно, з паузами; не обходити захист. Якщо сторінка недоступна, попросити викладачку скопіювати її через Claude in Chrome або надіслати скриншот редактора.
- **Не вигадувати синтаксис.** Лише те, що є в документації або підтверджено тестом.

## Статуси
DOCUMENTED (документація) · TESTED (реальний тест викладачки) · UNVERIFIED. Не називати TESTED без тесту.

## Вибір типу вправи (за навчальною метою)
| Мета | Блок |
|---|---|
| запам'ятати слова | Vocabulary, FlipCards, Matching |
| впізнати слово/форму | DragWords, DropDown |
| самостійно згадати форму | GapFill |
| перевірити розуміння | MultipleChoice, TrueFalse |
| порядок слів | Unscramble |
| відновити історію | SortSentences |
| класифікувати | ColumnSort |
| тренувати форми багаторазово | Заповніть таблицю (#Table) |
| письмо | Writing |
| говоріння | FlipCards (prompts), Картинка/Колаж, YouTube + обговорення |
| підказки, самоперевірка | HiddenText |
| домашнє фото/аудіо | Файл учня |
Не використовувати один тип для всіх цілей. Для молодших (5+, не читають): Matching «картинка-текст», DragWords з картинками, Unscramble з літерами + картинка, FlipCards з картинками, аудіо.

## Урок ReadyTo (генератор)
Структура уроку завжди за `../shared/preferences.md`: 60 хв, Warming up → лексика через ігри → граматика → текст (для тих, хто читає) → міні-тест 5–7 хв. Секції уроку ReadyTo = ці етапи.
1. Прочитати матеріал. 2. Визначити тему, рівень, лексику, граматику. 3. Цілі (can-do). 4. Підібрати блоки. 5. Послідовність. 6. Кожен блок у DOCUMENTED-форматі. 7. Список потрібних картинок/аудіо (Варіант B). 8. Перевірити відповіді й англійську. 9. `python3 ReadyTo/tools/check_import.py <файл>` — 0 помилок. 10. Зберегти в `lessons/YYYY-MM-DD_тема_рівень.txt` (+ `.md` з Варіантом B і ключами).
Видача: **Варіант A** — один текст для масового імпорту (у блоці коду). **Варіант B** — ручні блоки з точними налаштуваннями.

## Синхронізація з teaching/
- Якщо в `teaching/` є урок/презентація на ту саму тему — брати лексику й граматику звідти, не дублювати.
- До вправ ReadyTo пропонувати офлайн-ігру з `../shared/games-library.md`.
- Виправлення викладачки → `../shared/readyto-formats.md` («Перевірені виправлення») + `changelog.md`.
