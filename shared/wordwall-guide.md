# Wordwall — довідник

> ⚠️ Статус перевірки: на 2026-11-09 офіційні сторінки wordwall.net недоступні з цього середовища. Відомості нижче — загальновідомі, потребують підтвердження. Після тесту — ✅.

## Ключові факти
- Створення: Create Activity → обрати шаблон → ввести вміст вручну у поля. ⚠️
- **Імпорту файлів (CSV/Excel) — офіційно не підтверджено.** ❌/⚠️ Не обіцяти автоімпорт.
- Вставлення багаторядкового тексту в одне поле в деяких шаблонах розбиває його на окремі елементи — ⚠️ перевірити на конкретному шаблоні.
- **Switch template**: після створення той самий вміст можна перемкнути в інші сумісні шаблони — найбільша економія часу. ⚠️
- Зображення: можна додавати до елементів (вбудований пошук або завантаження). ⚠️
- Аудіо: ⚠️ не підтверджено для всіх шаблонів.
- Друковані версії (printables) для частини шаблонів. ⚠️
- Безкоштовний план (Basic) обмежений кількістю власних активностей і набором шаблонів; Pro — без обмежень. ⚠️ точні цифри перевірити на сторінці pricing.

## Шаблони (поширені) і що я готую
| Шаблон | Структура даних | Порада |
|---|---|---|
| Match up | пари: термін — визначення | 6–12 пар; без схожих визначень |
| Quiz / Gameshow quiz | питання + 1 правильна + 2–3 дистрактори | одна однозначна відповідь |
| Group sort | категорії → елементи | 2–4 категорії, 4–8 елементів у кожній |
| Anagram | слова (+ підказка) | перевіряти правопис, без пробілів у простих версіях |
| Unjumble | речення | слова розбиваються за пробілами; пунктуація — частина слова |
| Missing word | текст + слова для пропусків | граматично однозначні пропуски |
| Complete the sentence | текст з пропусками | як Missing word |
| True or false | твердження + T/F | без «напівправди» |
| Random wheel / Spin the wheel | список елементів | теми для мовлення, питання |
| Open the box | список елементів/питань | питання для говоріння |
| Find the match, Whack-a-mole, Maze chase, Hangman, Wordsearch, Crossword, Flash cards, Labelled diagram, Speaking cards | ⚠️ доступність залежить від плану | |

## Формат видачі
Для кожної гри — блок, зручний для ручного введення по полях:
```
[Шаблон: Match up] [Назва активності] [Інструкція для учнів]
1. term — definition
```
Плюс файл `teaching/Wordwall/imports/YYYY-MM-DD_тема_шаблон.md`.
