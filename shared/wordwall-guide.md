## Що підтверджено ✅
- **Switch template**: створена активність перемикається в інший шаблон одним кліком (панель Switch template праворуч). Обмеження: Anagram і Wordsearch працюють лише з простим текстом. Якщо є зображення, цифри чи спецсимволи, перемкнути вдасться не завжди. Деяким шаблонам потрібен мінімальний обсяг вмісту. Простий список (Spin the wheel) не перетворюється на «питання — відповіді».
- **Generate With AI** (Standard/Pro): створює вміст за запитом АБО з **завантаженого документа**, або генерує схожий матеріал на основі введених прикладів.
- **Зображення**: у Quiz — і до питань, і до варіантів відповідей. У Match up можна зіставляти зображення з підписами.
- **Друк**: більшість шаблонів має друковану версію, є завантаження в PDF (Standard/Pro).
- **Візуальні стилі** змінюють фон, шрифти, звуки й музику. Майже в кожному шаблоні є таймер.
- **Імпорт CSV/Excel**: на офіційних сторінках НЕ згадується ❌. Не обіцяти.

## Не перевірено ⚠️
- Чи розбивається багаторядковий текст, вставлений в одне поле, на окремі елементи (перевірте в редакторі).
- Аудіо до окремих елементів.

## Найшвидший спосіб створення
1. Я готую вміст для ОДНОГО базового шаблону (найчастіше Match up або Quiz).
2. Ви вводите його в редакторі (або вставляєте мій текст у Generate With AI як «initial content»).
3. Решту ігор отримуєте через **Switch template** без повторного введення: Match up → Find the match / Flash cards / Gameshow quiz / Anagram.

## Що я готую для кожного шаблону
| Шаблон | Структура | Порада |
|---|---|---|
| Match up / Matching pairs / Find the match | пари: термін — визначення/переклад/картинка | 6–12 пар |
| Quiz / Gameshow quiz / Image quiz / Win or lose quiz | питання + 1 правильна + 2–3 хибні | одна однозначна відповідь |
| Group sort / Speed sorting | категорії → елементи | 2–4 категорії |
| Anagram / Spell the word / Hangman / Wordsearch / Crossword | слова (лише простий текст) | перевіряти правопис |
| Unjumble / Word magnets | речення | пунктуація прикріплена до слова |
| Complete the sentence | текст з пропусками + слова | граматично однозначні пропуски |
| True or false | твердження + T/F | без «напівправди» |
| Spin the wheel / Open the box / Speaking cards / Flip tiles | простий список питань/слів | для говоріння, warming up |
| Labelled diagram | зображення + підписи | для дітей, які не читають, — з картинками |
