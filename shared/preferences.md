# Уподобання викладача (підтверджені)

> Заповнюється ЛИШЕ підтвердженими відповідями. Невідоме — позначено «❓ уточнити».

## Загальне
- Мова інструкцій для мене (викладача): українська.
- Мова матеріалів для учнів: англійська (рідна мова учнів у перекладах: ❓ уточнити — українська?).
- Предмет: англійська мова (❓ підтвердити).

## Учні та рівні
- Вік / тип учнів (діти, підлітки, дорослі; індивідуально/групи): ❓
- Рівні CEFR: ❓
- Підручники: ❓

## Уроки
- Тривалість уроку: ❓
- Онлайн / офлайн: ❓
- Обов'язкові етапи: ❓

## Презентації
- Формат (PowerPoint / Google Slides / Canva / інше): ❓
- Стиль, кольори, шрифти: ❓

## Інтерактивні платформи
- Wordwall / Quizlet / Baamboozle — тарифи (Free / платний): ❓
- ReadyTo — що це за платформа, посилання, формат вправ: ❓
