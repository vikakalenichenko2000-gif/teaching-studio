# Уподобання щодо інтерактивних ігор (Wordwall / Quizlet / Baamboozle)

> Лише підтверджені побажання. Невідоме — ❓.

- Тарифи: Wordwall **платний** · Quizlet **платний** · Baamboozle **платний** (✅ 2026-11-09) — можна пропонувати всі шаблони й функції платних планів.
- Мова матеріалів: **англійська** (✅).
- Quizlet: формат **слово — переклад** (✅); переклад **одним словом, якщо можливо, без синонімів** (✅).
  Мова перекладу: українська (❓ підтвердити).
- Вік від 5 років: для тих, хто не читає, — більше зображень, аудіо, простих шаблонів (Open the box, Random wheel, Match up з картинками).
- Кількість елементів за замовчуванням: Wordwall 10–15 · Quizlet 15–25 · Baamboozle 16–24 (❓ підтвердити)
- Улюблені шаблони Wordwall: ❓
- Формат видачі: готовий до копіювання блок у чаті + файл у відповідній папці.
