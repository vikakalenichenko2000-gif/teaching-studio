# Підручники

| Підручник | Клас / рівень | Файл (у `textbooks/` на комп'ютері) | Нумерація сторінок | Примітки |
|---|---|---|---|---|
| ❓ | | | друкована = PDF + ? | |

«Нумерація сторінок»: номер у підручнику часто не збігається з номером сторінки PDF. Зазначте зсув (наприклад, «PDF = друкована + 2»), щоб я відкривав правильні сторінки.
